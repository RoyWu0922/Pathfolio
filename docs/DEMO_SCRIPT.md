# Demo script (5–7 minutes)

Goal: a judge who has never seen Pathfolio can follow without narration notes on screen. Speak English during the demo if the agent is English; one Cantonese aside is fine.

## Clock

| Min | Beat |
| --- | --- |
| 0:00–0:45 | Problem. One chart or three numbers: 30,798 vacancies, −55%, NACE communication proficiency 53.5% employers vs 78.1% students.[4][5][7] Say we are not another chatbot. |
| 0:45–1:15 | Product one-liner. “One profile → three honest tracks → scored STAR pack → PDF you own.” Point at the ethics footer. |
| 1:15–2:00 | Load CityU sample. Do not type live. Three cards appear with **different** TrackFit numbers. Name the three tracks. |
| 2:00–3:30 | Open Analytics (or whichever is mid-score). Show SixPoint checklist. Accept one bullet diff. Open a STAR: colour the Action span, show 1–5 and the cap reason if any. |
| 3:30–4:30 | Interview plan: one “why they ask this” line. Seven-day row for the weakest NACE gap. |
| 4:30–5:15 | Export / print preview. Disclaimer visible. “Delete session” exists. |
| 5:15–6:00 | What GenAI did vs did not: drafted words; Python scored. Limits: hallucination, no offer prediction. PDPO strip-PII. |
| 6:00–6:30 | Who pays later: career centre licence. Who we will not serve: employers ranking students. |
| 6:30–7:00 | Buffer / questions. |

## Backup if the LLM is down

`PATHFOLIO_FIXTURE_MODE=true`. Practise this path the night before. Never start the demo on a cold API key.

## What not to say

- “We increase interview rates 10x.”
- “ATS will pass this.”
- “Our score predicts job performance.”
- “98.9% of HKU graduates have jobs” (wrong reading of GES).[16]

## Props

- One printed PDF of the sample report, in case the projector fails.
- This script on one card, not a slide wall.
